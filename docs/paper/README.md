# Paper bundle (placeholder)

This directory will hold the paper engineering artifacts (WP26):

- `experiment-matrix.md` — the three-arm experiment matrix (reference / upstream
  ForgeKernel @5030503 / Peregrine-Kernel) x operator set, ablations, cost structure;
- `repro.md` — hardware, drivers, clock protocol, seeds, task cards, commands, and the
  data-and-materials availability statement;
- result tables and figure pipeline outputs (CSV + LaTeX skeletons).

Nothing is here yet by design: every number in a paper must come from this framework's own
measured runs (the anti-fabrication discipline extends to the paper), and the first real A/B
numbers land via `docs/energize-protocol.md`. Upstream ForgeKernel's published numbers may
appear only as cited upstream results, never as this framework's own.
