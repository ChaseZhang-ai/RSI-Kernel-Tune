# SM86 (Ampere) interface index — CUDA mode

The sm86 tree of CUDA mode (single-file CUDA C++ student). Demand-driven: a recipe is
written when the student gets stuck on that interface, following `../TEMPLATE.md`, and is
marked ✅ on **only** one of the two kinds of evidence below. This file is not a plan; it
is the ledger of what has already been earned.

Two kinds of evidence earn ✅, nothing else does. **A GPU probe returning `PROBE PASS`**
is the default kind. The second exists because some knobs are **numerically invisible**:
**a shipped KEEP whose own NCU census shows the contract axis moved** certifies it, citing
the axis readings before and after the change and the gate-window readings.

This tree was scaffolded empty by the WP21 mini smoke (`tasks/wp21mini/`) so the local
RTX 3060 (sm86) can run the machine end-to-end; it registers zero recipes. **Not finding
something here does not mean it cannot be done** — the local CUDA headers, the PTX ISA and
your own probes are authoritative; what you win on a probe gets written in here in the
finish round.
