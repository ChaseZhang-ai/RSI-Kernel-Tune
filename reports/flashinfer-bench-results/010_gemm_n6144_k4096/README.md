# 010_gemm_n6144_k4096

The direct-launch baseline and tuned Triton file each passed all 43 official FlashInfer-Bench workloads on GB300. In two paired trials, the tuned file ran at 24.64 and 24.65 µs geometric mean versus 45.67 and 45.68 µs for the baseline. The paired speedup was 1.853× in both trials. The exact tuned file took 2.73 s over its first synchronized calls to all 43 shapes from an empty Triton cache, including JIT compilation and execution. The direct baseline took 1.51 s. Peak PyTorch allocations in the comparison harness were 0.78 GiB. [Official tuned traces](tuned-gb300.jsonl) · [Paired traces](tuned-paired-gb300.jsonl) · [Summary and source hash](tuned-gb300-summary.json)

The dispatch uses a GEMV for one row, swapped-operand TMA for small matrices, and persistent tensor-core GEMM for larger matrices. It writes the full FP16 destination once after FP32 accumulation. The official evaluator passed the unpadded 15- and 35-row cases at 16.67 and 17.47 µs. All 43 Parquet workloads had unique IDs and unique M values, and all generated inputs from the official random-input specification. [Official baseline traces](baseline-gb300.jsonl)

The baseline used GB300 physical index 1 with UUID `GPU-87e04b70-e9c6-0c59-7810-a2a4a6af4f12`, CUDA capability 10.3 and 152 queried SMs. The SM lock was 1500 MHz and active clock samples read 1500/3996 MHz. The driver rejected the immediate memory lock even though its command returned zero. The evaluator was SOL-ExecBench 1.0.2 at commit `a9fa0804c793d438e70850c33fe34426e66d53dd`, with PyTorch 2.10.0+cu130, Triton 3.6.0 and CUPTI Python 13.5.0. The evaluator used 10 warmups and 50 measured calls per workload, cold L2, cloned inputs, preallocated destinations, and first-to-last CUPTI activity timing. A foreign context interrupted the first GPU attempt. The entire baseline was rerun on GPU 1.

The tuned official and paired runs also used physical GPU 1. Its active samples read 1500/3996 MHz. The driver accepted a deferred 3996 MHz setting and requested a driver reload, so the memory clock evidence is the active readback. Exploratory trials also used physical GPU 0, UUID `GPU-abbc4299-8500-54d7-2a37-3ccac762f30d`, with the same queried capability and SM count. Each trial pairs a candidate with the direct baseline under the same GPU lock. The trial logs cover N tiles of 64, 128 and 256, clustered middle-size tiles, persistent waves at 148 and 152 local SMs, and segmented TMA epilogues.
